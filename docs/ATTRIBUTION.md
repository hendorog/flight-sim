# Third-party data shipped with the simulator

The repository's own code and assets are GPLv3+ (see LICENSE). The files below come from elsewhere; each
directory's SOURCE.md records, per file: the source page and exact download URL, the licence line as read on the
source page, the credit to give, how the shipped file was derived from the download (script under scripts/sky/),
and the SHA-256 of both the download and the shipped file.
